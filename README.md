## 🚀 Projects

<table>
<tr>
<td width="50%" valign="top">

### 🏠 Metaverse Flat Marketplace
A real-world property tokenization platform. Book flats (ID 1–300) as on-chain tokens — each flat is a unique asset you own, trade, and verify without a broker. Built with a deep purple × teal metaverse aesthetic.

**What it does**
- Book any flat by ID against ETH
- Load all available flats from contract
- Check contract balance live
- Owner withdrawal function

**Stack:** `Solidity` · `ethers.js` · `MetaMask` · `HTML/CSS/JS`

</td>
<td width="50%" valign="top">

### 💎 Ayu Wallet
A non-custodial Web3 wallet with DeFi built in. Tracks ETH portfolio across Ayu Wallet and MetaMask balances in one dashboard, with live ETH/USD price, Sepolia testnet support, and a full activity + contacts + assets tab system.

**What it does**
- Real-time ETH portfolio display
- MetaMask + Ayu Wallet dual-balance tracking
- Live ETH price feed
- Activity, Contacts, Assets, Settings tabs
- Sepolia & Holesky testnet support

**Stack:** `Solidity` · `ethers.js v6` · `Chainlink Oracles` · `MetaMask` · `Vanilla JS`

</td>
