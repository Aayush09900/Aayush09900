## 🚀 Featured Projects

### 💎 Ayu Wallet — Non-Custodial ETH Wallet DApp

A wallet-style Web3 DApp connected to an Ethereum Sepolia smart contract.

**Highlights**
- MetaMask + Sepolia integration
- Wallet balance and contract balance
- ETH deposit, withdrawal, and transfer flows
- On-chain activity and transaction links
- Trusted contacts and wallet security state
- Responsive production-style dashboard
- GitHub Actions validation + GitHub Pages deployment

**Stack:** `Solidity` · `ethers.js v6` · `MetaMask` · `JavaScript` · `HTML` · `CSS`

**Repository:** https://github.com/Aayush09900/ayuwallet_daap

**Live DApp:** https://aayush09900.github.io/ayuwallet_daap/

---

### 🏠 Metaverse Flat Marketplace — On-Chain Property Booking

A Web3 property marketplace that loads flat inventory from a deployed Sepolia smart contract and allows users to book available flats through MetaMask.

**Highlights**
- Live on-chain flat inventory
- Availability and search filters
- Wallet and contract balance visibility
- Real booking transactions with confirmation states
- `FlatBooked` event activity and Etherscan links
- Responsive UI and deployment-ready CI/CD
- GitHub Pages deployment workflow

**Stack:** `Solidity` · `ethers.js` · `MetaMask` · `JavaScript` · `Parcel`

**Repository:** https://github.com/Aayush09900/metaverse-flat-marketplace

**Live DApp:** https://aayush09900.github.io/metaverse-flat-marketplace/
