## 🚀 Projects

<table>

<td width="50%" valign="top">

### 🏠 Metaverse Flat Marketplace

Real-world property tokenization platform. Each flat (ID 1–300) is minted on-chain — book, verify ownership, and trade without a broker, built on a dark purple × teal metaverse aesthetic.

**Features**
- Book any flat by ID against ETH
- Load all listed flats from contract state
- Live contract balance check
- Owner-only withdrawal

**Stack:** `Solidity` · `ethers.js` · `MetaMask` · `HTML` · `CSS` · `JS`

</td>
<td width="50%" valign="top">

### 💎 Ayu Wallet

Non-custodial Web3 wallet with built-in DeFi lending. Tracks Ayu Wallet + MetaMask balances in one portfolio dashboard, live ETH/USD price feed, and a full tab system: Home, Activity, Contacts, Assets, Settings.

**Features**
- Total portfolio view across wallets
- Dual balance: Ayu Wallet + MetaMask
- Live ETH price via Chainlink
- Sepolia & Holesky testnet support
- DeFi: deposit, borrow, repay, health factor

**Stack:** `Solidity` · `ethers.js v6` · `Chainlink` · `MetaMask` · `Vanilla JS`
